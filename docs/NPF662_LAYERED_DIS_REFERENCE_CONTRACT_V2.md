# NPF662 conventional layered DIS contract V2

This extends `formulation="mf6_6_6_2_npf"` to `geometry="structured_dis_layered"`, not transformed terrain. Version-pinned reference: MF6 6.6.2 DIS, NPF harmonic averaging, no XT3D, physical unrotated Cartesian Kx/Ky/Kz. Existing scalar-dz V1 inputs, hashes and defaults retain their original interpretation. Layered inputs use separate schema2 and case identity.

The loader also recognises the early confined V1 encoding that omitted ICELLTYPE (implicitly0): its original12-field hash and save roundtrip are preserved without adding a dataclass field. Explicitly changing its cell type moves it to the explicit encoding/hash. New layered geometry is differenced in FP64 even when raw elevations were supplied as float32; raw input representation remains part of the hash. Native decoding requires the exact canonical adjacency edge set, including no vertical pass-through at an internal inactive cell.

Canonical arrays use (k top-down,j south-to-north,i west-to-east). Interfaces have shape(nz+1,ny,nx). Owning top/bottom are interfaces[k]/interfaces[k+1], T=top-bottom, zcentre=.5top+.5bottom, volume=dx*dy*T. dx/dy are positive scalar spacings. All supplied interfaces and derived geometry must be finite and positively thick, including unused inactive placeholders; masks0/1 exclude connections through holes. No -1 pass-through, pinch-outs, crossing layers, zero thickness, horizontal variable spacing or rotated tensors. Each positive active material component must have a prescribed datum. Prescribed/source ownership follows V1 unchanged.

`build_from_layers(z_interfaces=...,kx_field=...,ky_field=...,kz_field=...,active=...,bc_mask=...,bc_values=...,rhs=...,initial_head=...)` is a separate builder. Interfaces are authoritative: constructor dz is unused in this mode and session.dz=None; solve-time top overrides are rejected. Recalling the builder rebuilds geometry/workspace even for the same shape, reporting no workspace reuse. RHS/initial/boundary-value updates preserve compatible buffers with fresh cold state; topology reconstruction closes old connectivity/buffers. Arbitrary face overrides and terrain builds do not acquire this identity.

For an x face, C0=dy/[(dx/2)/(Kxi*Ti)+(dx/2)/(Kxj*Tj)]; for y interchange dx/dy/K. Vertical C0=dx*dy/[(Ti/2)/Kzi+(Tj/2)/Kzj]. These are **same-k conventional DIS** connections. They do not use physical overlap, sloping face area, Euclidean centre separation, cross-layer horizontal adjacency or tensor/metric corrections. h=z can therefore produce lateral flow; no terrain-equivalence claim follows.

Derivation was checked before production implementation against official tag6.6.2, source commit7cb7958940186ecfdcd3ea9e6a563cc4609581c9. `Connections.disconnections` uses half DELR/DELC and perpendicular width for horizontal faces, half owning thickness and dx*dy for vertical faces. `GwfConductanceUtils.condmean` default harmonic is equivalent to the resistances above. `gwf-npf.calc_initial_sat/calc_condsat` initializes full thickness for these options; `vcond` with VARIABLECV off returns that constant. `hcond/convertible_upstream` uses higher-head saturation, choosing the larger MF6 user node at ties. Sources are preserved in historical `mf6_source/` plus this campaign's `contract/Connections.f90`. The tagged source is not claimed as the executable's exact build provenance.

Two preimplementation all-CHD **constitutive verification models**, confined and Newton-convertible, use independently varying/disjoint lateral elevations. Heads do not advance. Same-head flux errors <=2.85e-14m³/day confirm the stated equations. Their zero all-CHD solver residual is not a free-equation/root validation. Native executable/path/version/checksum remain exactly V1.

The unconfined extension retains the V1 quadratic saturation epsilon1e-6, now t=clip((h-bottom_i)/Ti,0,1) and ds/dh includes1/Ti. Confined s=1, ds/dh=0. Horizontal C=C0*s_donor if either endpoint convertible; vertical C=C0. At equal heads, different bottoms/T can give different saturations even with both endpoints convertible: x+ donor is canonical right, y+ donor canonical left after MF6 row reversal. Test selected one-sided directions, not a central derivative across a donor switch. Convertible CHD must meet its own actual bottom; invalid supplied all-CHD states are rejected without retyping or changing heads.

Steady CHD/no-flow/unreduced volumetric WEL only. No STO, RCH, GHB, DRN, river or custom contacts. XT3D, THICKSTRT, VARIABLECV, DEWATERED, PERCHED and REWET remain off; alternative averaging and floor laws are unsupported. There is no positive terrain floor. R=Q-div(q), one face/opposite incidence. J=D(div q), J*delta=R; dq=C*(vi-vj)+DC[v]*(hi-hj). Only endpoints enter each flux: at most seven spatial columns per row before prescribed elimination. Fixed corrections remain zero.

Layered confined and unconfined device solves use the existing restarted GMRES/Newton controller, diagonal preconditioner and full-saturated safeguard; no K-cycle integration is introduced. Full-saturated principal P0=sum(C0) yields fixed S=1/P0 on both J/R. All attempts share the per-outer Krylov budget and candidates remain separate from accepted linearizations. Uniform confined legacy backend behavior is preserved. Layered confined honours explicit physical/relative final thresholds; unconfined retains fixed V1 acceptance.

Default final acceptance: finite valid operands/aggregates and active heads, CHD absolute error<=1e-10m, head-equivalent RMS<=1e-6m, AND(physical RMS<=1e-12m³/day OR L1/gross<=1e-8), with original tiny-throughput denominator. No signed-cancellation substitution. Same-head C tolerance3e-13 relative/zero absolute; same-head flux/residual3e-12relative+2e-11m³/day; converged head1e-7m absolute on controls. These unchanged thresholds precede the new cold-solve results. Native numerical iteration controls are separate and may be scaled to representable head magnitudes as declared in V1; native success alone never passes the gate.

References: official [6.6.2 DIS](https://modflow6.readthedocs.io/en/6.6.2/_mf6io/gwf-dis.html), [NPF](https://modflow6.readthedocs.io/en/6.6.2/_mf6io/gwf-npf.html), and the preserved tagged source paths above. This bounded conventional layered approximation does not establish physical groundwater validation, uniqueness or general terrain equivalence.

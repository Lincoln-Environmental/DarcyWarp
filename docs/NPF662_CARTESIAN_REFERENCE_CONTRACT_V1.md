# NPF662 Cartesian reference contract v1

This bounded formulation is `mf6_6_6_2_npf`: structured DIS, unrotated physical Cartesian diagonal positive K, orthogonal cells, uniform scalar dx/dy/dz (dx need not equal dy), flat contiguous layers. It is not universal MODFLOW compatibility or terrain equivalence. The legacy Cartesian default and experimental transformed terrain remain distinct. Stage0 must pass before this contract's implementation; confined parity must pass before its unconfined extension.

Units: metres, days, volumetric cell Q [m³/day], K [m/day], C [m²/day]. Arrays C-order(k top-down,j south-to-north,i west-to-east); MF6 reverses j. Heads are cell-centre total hydraulic heads. CHD constrains that cell's unknown, not an exterior face. Exterior and inactive-neighbour faces are no-flow. IDOMAIN is0/1 only; vertical pass-through is unsupported. Source on inactive cells is rejected. Original source on fixed cells is retained and reported as reservoir forcing; it is excluded from free equations and from WEL allocation rather than redistributed. Reservoir exchange includes that declared forcing when a full reservoir budget is requested.

For an internal orthogonal face with normal axis a, area A and centre distance d:

```
C0 = A / ((d/2)/K_a,i + (d/2)/K_a,j)
q_i_to_j = C0 * (h_i-h_j)
R_i = Q_i - sum(outward face flows)
```

Each face is evaluated once and enters neighbours with opposite incidence. Confined cells have ICELLTYPE=0, full thickness independent of head, default harmonic material averaging, no GWF NEWTON. The independent sparse physical matrix is incidence*C0*incidence.T; fixed heads are eliminated for CPU factorization. Every active hydraulic component requires a genuine fixed-head datum; ungrounded balanced/incompatible components are rejected, never arbitrarily pinned.

Pinned native reference: MF6 6.6.2 executable/checksum in stage0/runtime.json. DIS, NPF XT3D=off; K/K22/K33 physical components, ratio flags off, ANGLE1/2/3=0, alternative averaging absent, THICKSTRT/VARIABLECV/DEWATERED/PERCHED/REWET=off; no STO, transient warmup, RCH, DRN, GHB or terrain contacts. CHD and exact full-precision SOURCE WEL only, AUTO_FLOW_REDUCE absent. One steady period, native output HEAD/FLOW-JA/DATA-SAT/GRB and full IMS listing/outer/inner records retained. Reference solves use COMPLEX, outer/inner DVCLOSE1e-14m and STRICT RCLOSE1e-14m³/day, with the final linear configuration below; those iteration criteria differ from the independent gate. The initial1e-12 BICGSTAB run narrowly failed independent balance in the strong vertical-resistance case; it is retained. Tightening native iteration accuracy changes no equations or acceptance criterion.

Before inspecting results, declare conductance relative tolerance3e-13 with zero absolute floor; arbitrary-head face/residual tolerance3e-12 relative plus2e-11m³/day absolute; complete head comparison1e-7m absolute for the finite declared controls. Independent discrete acceptance requires valid active finite heads and prescribed heads within1e-10m absolute, head-equivalent RMS<=1e-6m AND (physical RMS<=1e-12m³/day OR residual L1/gross external throughput<=1e-8). Tiny throughput uses float64.tiny. Prescribed/inactive rows cannot dominate statistics. Datum/conditioning and stricter residual diagnostics must explain material head differences; tolerances will not be widened to hide them.

MF6 supplied-state checks constrain all active heads in a **separate verification model**, prove no head advance, and read physical face fluxes. Original Q and free mask then reconstruct the original problem's supplied-head residual independently; a zero all-CHD solve residual is not the result being tested. Cold complete models remain separate. Native success, exact source allocation, independent conservation, formulation compatibility and solution agreement are reported separately.

The strict face tolerance applies at identical heads. For independently converged heads, first enforce the declared head gate; the confined flux difference is bounded by `C0*(abs(delta_h_i)+abs(delta_h_j))` plus the same-head arithmetic allowance. Applying the supplied-head tolerance directly to differing solutions confuses head roundoff amplified by large C with an operator defect. The first high-contrast small test exposed exactly that distinction (3.84e-11m³/day difference). No same-head/operator tolerance is widened.

Final confined native numerical configuration uses CG (this constrained confined matrix is SPD), symmetric DIAGONAL scaling, ILUT fill100/drop0, relaxation.97 and the1e-14 controls above. Sequential one-factor tests of tighter tolerances, CG, zero dropping and scaling alone still failed the high-contrast layer's physical gate; increasing fill finally gives physical RMS8.27e-15m³/day. All failed native runs are retained. This is reference-solve effort, not an improved discretisation or permission to accept the earlier native success flags. The unconfined Newton matrix will use a nonsymmetric method.

Default harmonic averaging, optional flags and ICELLTYPE semantics are documented; precise upstream/tie, smoothing and full-thickness initialization are source-confirmed, not inferred from names in the earlier evaluator. That evaluator has different scope (full unstaggered terrain stacks and optional custom contacts); it is checked on the shared flat subset rather than treated as the new oracle.

The unconfined addendum will define the selected NEWTON law only after the confined gate passes. Stage3 variable layer geometry and local GHB/DRN, Stage4 transient/storage/surface coupling and SHANZ, and multipoint/rotated/Richards research are explicitly deferred.

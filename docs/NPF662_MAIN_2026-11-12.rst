The public history timer includes internal workspace construction, graph capture,
all source/timestep updates, production physical acceptance and output download.
External model construction and extra independent benchmark audits are separate.
MF6 output writing remains inside its engine timer. FP64 physical heads,
storage, fluxes, FGMRES and acceptance use an explicitly selected FP32
multigrid correction. The strict relative cell imbalance limit is 1e-7;
head-equivalent RMS remains 1e-6 m. The 1.5e-7 profile matches the saved
MF6 history's measured physical accuracy envelope; it does not equate
the differently defined solver convergence norms.

All 400 NPF endpoints pass independent physical audits and MF6 head gates.
The cached 8 x 8 x 5 Cartesian steady and four-step transient sanity cases
also pass after warmup and three repetitions. These are smoke checks,
not new realistic-size Cartesian performance claims.

Validation on main: 615 tests passed, four CPU parameterizations of CUDA-only
checks skipped, and 43 fresh-MF6 tests deselected. Experimental terrain
APIs remain on dev. The release uses the explicit ``solve_transient_npf``
API and the checked-in strict, MF6-accuracy and confined control profiles.
Library defaults remain unchanged. Reproduction commands and limitations
are in ``NPF662_RUNTIME_SEARCH.rst`` below.

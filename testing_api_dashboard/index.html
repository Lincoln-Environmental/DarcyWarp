DarcyWarp: Verified GPU-accelerated multigrid for repeated-solve groundwater workflows in 2D transmissivity form

Patrick Durney, Jaco Fourie
Lincoln Agritech Ltd, Lincoln University, New Zealand

Repeated steady-state groundwater solves often bottleneck calibration and uncertainty workflows. DarcyWarp provides a verified GPU multigrid backend that matches MODFLOW 6 heads and residuals while delivering large speedups for repeated-solve ensembles.

Highlights

  • Verified GPU multigrid solver for repeated-solve 2D transmissivity workflows.
  • Matches MODFLOW 6 heads, residuals, and mass-balance under matched stresses.
  • Supports recharge, prescribed head, no-flow, and general-head exchange.
  • Delivers 2 to 72x end-to-end speedups for 10^5 to 9x10^6 active cells.
  • Reproducible benchmarking harness with fixed ensembles and plotting workflow.

Bench and plot script

  --nx 1000 \
  --ny 1000 \
  --dx 100.0 \
  --n_cases 48 \

  --seed 42 \
  --device cuda:0 \
